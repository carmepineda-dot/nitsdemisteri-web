# nitsdemisteri-web

Web de presentació de **Nits de Misteri** (joc de mates per a primària, en català) i política de privacitat que demana Google Play.

- HTML i CSS estàtics, sense dependències ni recursos externs (ni fonts de Google ni analítica).
- Publicat amb GitHub Pages des de la branca `main`, carpeta arrel.
- El domini propi es configura al fitxer `CNAME` i a la zona DNS del registrador.

Estructura:

```
index.html          portada
privacitat/         política de privacitat (ca + es)
avis-legal/         avís legal LSSI (ca + es)
404.html            pàgina no trobada
site.css            estils comuns
fonts/              Fredoka i Nunito (SIL OFL)
img/                icona i captures reals del joc
```

El codi del joc és en un repositori privat a part.
